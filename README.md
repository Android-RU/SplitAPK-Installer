# Умный инсталлятор сплит-APK (install-multiple)

SplitAPK-Installer `split_apk_installer.py` — это умный установщик для Android-устройств через ADB. Скрипт автоматически подбирает нужные APK-сплиты (ABI, плотность, язык и т.п.) под конкретное устройство и выполняет установку через `adb install-multiple`.

---

## 📌 Возможности

- Автоматический поиск `base.apk` и необходимых сплитов (`config.abi`, `config.dpi`, `config.lang`, `feature-*`).
- Работа с директориями, отдельными `.apk` файлами, а также архивами `.apks` и `.xapk`.
- Сопоставление сплитов с параметрами устройства:
  - ABI (`arm64-v8a`, `armeabi-v7a`, `x86_64` и др.)
  - плотность экрана (DPI)
  - локаль (например, `ru`, `en`)
  - версия SDK
- Установка через `adb install-multiple` с поддержкой опций:
  - `-r` — перезапись существующей версии  
  - `-d` — даунгрейд (если версия ниже)  
  - `-g` — автогрант разрешений  
  - `--staged` — staged install (Android 10+)  
- Режим **dry-run** (только печать команды установки, без выполнения).
- Вывод результата в человекочитаемом виде или в формате JSON (`--json`).
- Подробное логирование (`--verbose`).
- Кроссплатформенный, работает на Linux, macOS и Windows.

## 🚀 Установка и запуск

### Требования
- Python 3.9+
- Установленный и доступный в `PATH` **adb** (Android Debug Bridge)

### Клонирование репозитория
```bash
git clone https://github.com/Android-RU/SplitAPK-Installer.git
cd SplitAPK-Installer
````

### Запуск

```bash
python split_apk_installer.py <путь_к_apk/директории/архиву> [опции]
```

---

## ⚙️ Примеры использования

### Установка набора сплитов из директории

```bash
python split_apk_installer.py ./myapp_splits/ --grant-all --replace
```

### Установка из `.apks` архива (как в bundletool)

```bash
python split_apk_installer.py app.apks --dry-run --json
```

### Установка из `.xapk` файла

```bash
python split_apk_installer.py MyApp.xapk --device emulator-5554
```

### Установка с разрешением даунгрейда

```bash
python split_apk_installer.py ./splits/ --downgrade
```

## 📖 Опции командной строки

```
usage: split_apk_installer.py [sources...] [опции]

Источники:
  - файлы .apk
  - директории со сплитами
  - архивы .apks или .xapk

Основные опции:
  --device SERIAL     Установить на конкретное устройство
  --dry-run           Только печать команды установки
  -r, --replace       Разрешить замену установленного приложения
  -d, --downgrade     Разрешить даунгрейд (установка версии ниже)
  -g, --grant-all     Автоматически грантить все разрешения
  --staged            Использовать staged install (Android 10+)
  --json              Вывод результата в JSON
  -v, --verbose       Подробный вывод
```

## 📋 План работы скрипта

1. Сбор входных файлов (`.apk`, `.apks`, `.xapk`, директории).
2. Обнаружение `base.apk` и сопутствующих сплитов.
3. Снятие параметров устройства (ABI, SDK, плотность, локаль).
4. Подбор подходящих сплитов.
5. Формирование плана установки.
6. Выполнение установки через `adb install-multiple`.
7. Вывод результата (в консоль или JSON).

---

## 🔧 Ограничения и примечания

* Скрипт не требует root-доступа.
* Поддерживается только установка (удаление приложений не реализовано).
* Для распаковки `.apks/.xapk` используется стандартный `zipfile` Python.
* Для точного разбора `AndroidManifest.xml` можно дополнительно установить библиотеку **androguard**, но она не обязательна.
